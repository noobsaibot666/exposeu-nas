# WHAT NOT TO BUILD

Avoid pages for:

- general event photography
- wedding photography
- corporate headshots
- private parties
- club photography
- influencer content packages
- real estate photography
- family / lifestyle portraits
- generic videography Berlin

These dilute the expose.u brand.

# FINAL RECOMMENDATION

The next expansion should not be more broad.

It should be more specific.

The best new landing pages are not new services. They are sharper entry points into existing services.

Best strategic pattern:

## Core Service

Brand & Agency Documentation

## Landing Pages

- Experience Design Documentation
- Award Submission Documentation
- Brand Activation Documentation
- Trade Fair & Expo Documentation

This lets expose.u expand commercially while staying inside the same brand logic:

> Temporary projects become long-term visual assets.
