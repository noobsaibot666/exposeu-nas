# Global Codex Prompt — Improve Landing Page Hero, Copy, and Sales Flow

Use this prompt when you want Codex or another Dev AI to review and improve any service/product landing page so it directs the prospect toward inquiry, booking, purchase, or contact.

---

## Prompt

Review the current landing page/component and improve the hero section, copy, section order, and CTA flow so the page works as a clear sales funnel instead of a brochure.

### Main goal

Make the page help the right prospect quickly understand:

1. What is being offered
2. Who it is for
3. What problem it solves
4. What result they get
5. What action they should take next

The page should guide the visitor toward the main conversion action, such as contact, booking, inquiry, purchase, or starting a project.

---

## Hero section rules

The hero must answer these questions in under 5 seconds:

- What is this service/product?
- Who is it for?
- What concrete result does it create?
- Why should the visitor trust it?
- What should they click next?

Improve the hero with:

### 1. Clear headline

Use the customer's language, not internal jargon.

Avoid vague headlines like:

- Creative solutions for modern brands
- Premium content services
- Full-service production support
- Better tools for growth

Use specific headlines like:

- Photo and video assets for artists preparing a release
- Booking-ready visuals for venues and performers
- Campaign content for creators launching something new

### 2. Concrete subheadline

The subheadline should define the ICP and the result.

Formula:

`For [specific audience] who need [specific outcome] before [specific moment/event].`

Example:

`For musicians, DJs, bands, and performers who need press photos, short clips, and social assets before a single, album, show, or campaign goes live.`

### 3. Real visual proof

Use real work, screenshots, case studies, product UI, client results, or portfolio images.

Avoid generic illustrations, stock images, or decorative visuals that do not prove the offer.

### 4. Specific CTA

Use a CTA that matches the visitor's intent.

Avoid vague CTAs like:

- Learn more
- Get started
- Discover

Use specific CTAs like:

- Tell us about your release
- Book a session
- Request a quote
- Start your project
- Send us your brief

### 5. Immediate proof above the fold

Add one small trust signal close to the hero:

- client logos
- testimonial quote
- number of projects
- featured artists/brands
- real result
- portfolio preview

---

## Page sequence rules

Reorder the page into a simple funnel:

### 1. Promise / Hero

Say exactly what the offer does and who it is for.

### 2. Problem / Opening

Show that the page understands the visitor's situation.

Use direct language:

`You have [important thing coming]. Now you need [specific support/result].`

### 3. Proof

Show real visuals, testimonials, logos, screenshots, examples, or portfolio work early.

### 4. Offer clarity

Explain what the visitor gets in short bullets or cards.

Do not use long paragraphs.

### 5. Use cases / Outcomes

Show where or how the result will be used.

Example:

- social media
- press
- websites
- ads
- booking
- campaigns
- presentations

### 6. Objection handling

Answer the doubts that may stop the visitor from clicking.

Examples:

- Not sure what you need?
- Need it quickly?
- Not comfortable on camera?
- No big production budget?
- Already have some assets but need better campaign content?

### 7. Final CTA

End with one clear action.

The final CTA should repeat the main conversion goal.

---

## Copy style rules

Keep the copy:

- direct
- specific
- human
- easy to understand
- benefit-led
- action-focused
- written in the customer's language

Avoid:

- jargon
- abstract brand language
- long paragraphs
- repeated explanations
- generic claims
- brochure-style copy
- over-explaining the process
- poetic lines that do not explain the offer

Every section should either:

1. Clarify the offer
2. Build trust
3. Remove doubt
4. Move the visitor toward the CTA

If a section does none of these, remove it or merge it.

---

## CTA direction

Make CTAs specific to the page goal.

Use one main CTA consistently across the page.

Examples:

- Tell us about your release
- Book a release session
- Start your content kit
- Request a quote
- Send us your brief
- Plan your session

Avoid using too many different CTA labels on the same page.

---

## Section reduction rules

Reduce the page if it feels too long.

Prefer fewer, stronger sections instead of many small brochure sections.

Recommended structure:

1. Hero
2. Who it is for / what situation it solves
3. What you get
4. Proof
5. Where or how it is used
6. Final CTA

Keep paragraphs under 2–3 lines.
Use bullets, cards, chips, and short blocks where possible.

---

## Developer instructions

- Analyze the existing copy before rewriting.
- Improve the hero, section sequence, CTA labels, and text density.
- Keep the existing visual style unless a layout change is needed for clarity.
- Do not change global/shared CSS class names unless necessary.
- Use unique class names for any new styles.
- Do not break existing routing or components.
- Return updated page/component code only.

---

## Final quality check

Before finishing, check:

- Can the right prospect understand the offer in 5 seconds?
- Is the headline specific enough?
- Is the CTA clear and repeated?
- Is the page moving toward contact, booking, purchase, or inquiry?
- Is there proof before the visitor has to scroll too far?
- Is every section helping conversion?
- Is the copy clean, direct, and easy to understand?
